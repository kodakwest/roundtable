Project: Roundtable Sermon Guides
v1.0 roundtable.logos-core.com

1. Overview

Roundtable is a sermon discussion guide web application for Harvest Ridge Church. It allows users to browse, search, and view structured sermon discussion guides. Guides are stored in a Cloudflare D1 database (with static JSON fallback for development). An admin interface at /admin allows authors to paste markdown, parse it into the Guide schema via a Worker, preview/edit, and one-click publish to D1.

2. Architecture

The system uses Cloudflare Pages for hosting static assets and Pages Functions for the API layer, connecting to a D1 database.

3. Data Model

Guide Type Definition

export type GuideQuestion = { id: string; prompt: string; }
export type GuideSection = { title: string; context: string; questions: GuideQuestion[]; }
export type GuideLanding = { paragraph: string; finalQuestion: string; }
export type SeriesMeta = { id: string; name: string; count: number; }
export type Guide = {
  id: string; title: string; series: string; date: string;
  scriptureMap: string;
  anchorVerse: { reference: string; text: string; };
  theme: string; framingSentence: string;
  sections: GuideSection[];
  landing: GuideLanding;
}

D1 Schema

CREATE TABLE IF NOT EXISTS guides (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL, series TEXT NOT NULL, date TEXT NOT NULL,
  scripture_map TEXT NOT NULL,
  anchor_reference TEXT NOT NULL, anchor_text TEXT NOT NULL,
  theme TEXT NOT NULL, framing_sentence TEXT NOT NULL,
  sections TEXT NOT NULL,  -- JSON array of sections
  landing_paragraph TEXT NOT NULL, landing_question TEXT NOT NULL,
  created_at TEXT DEFAULT (datetime('now')),
  updated_at TEXT DEFAULT (datetime('now'))
);

4. Pages Functions API

GET /api/guides

Returns all guides from D1 sorted by date DESC.

  • Auth: None
  • Response: { guides: Guide[] }
curl https://roundtable.logos-core.com/api/guides

POST /api/admin/parse

Parses markdown via regex into the Guide schema.

  • Auth: None
  • Request: { markdown: string }
  • Response: { guide: GuideJSON, confidence: number, warnings: string[] }
curl -X POST https://roundtable.logos-core.com/api/admin/parse   -H "Content-Type: application/json"   -d '{"markdown":"# Guide Title..."}'

POST /api/admin/guides

Validates and saves a guide into D1.

  • Auth: X-Admin-Key: <key>
  • Request: { guide: GuideJSON }
  • Response: { success: true, id: string }
curl -X POST https://roundtable.logos-core.com/api/admin/guides   -H "Content-Type: application/json"   -H "X-Admin-Key: your_admin_key"   -d '{"guide": {...}}'

5. Admin Interface

1. Auth (AdminLogin): Uses a shared-key gate (env.ADMIN_KEY), saved in sessionStorage.
2. Dashboard (AdminDashboard): Lists current guides and provides an "Add New Guide" entry point.
3. Paste & Parse: GuideComposer provides a spacious, writing-tool feel text area for markdown.
4. Preview & Edit: Converts markdown to an editable preview form with confidence scoring.
5. Publish: One-click publish to D1, immediately live on the site.

7. Guide Pipeline

  • CLI Import: scripts/import-guide.py reads markdown, generates JSON to src/data/guides/.
  • Worker Parser: functions/api/admin/parse.ts ports the python logic to TS regex. Confidence scoring ensures data quality.
  • Static JSON Fallback: If API fails or in dev mode without functions, src/lib/guideData.ts loads static JSONs.
  • D1 Storage Flow: Valid JSON is inserted into guides table. sections array is stringified to JSON in the DB.

9. Deployment

  • Auto-deploy: Git push to main branch triggers Cloudflare Pages build.
  • Domain: roundtable.logos-core.com (also roundtable-cz3.pages.dev)
  • Database: D1 roundtable-guides (id: 5a6f5c60-c926-4fa1-a53c-f2c97f090d7e)
  • Secrets: env.ADMIN_KEY must be set in Cloudflare via dashboard or wrangler.
